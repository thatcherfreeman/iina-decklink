Most settings live in Plugin → DeckLink Settings…, which lists the devices and output resolutions your hardware actually reports. Set the resolution to whatever your monitor expects — the picture is scaled to it and only the frame rate is negotiated against the file. This page covers the few settings that are set once.

Off by default, so opening IINA doesn't take over a card another application may be using.

Behaviour when IINA isn't frontmost is set from the settings window too — Do nothing, Blank to black (keeps the card, but stops showing a frozen frame while you're away), or Release the device (hands it to Resolve or a capture application instead).
Helper binary:

Leave blank to use the copy in the plugin's data folder, which is what the first-run download installs. Set this to point at a local build instead — the path to iina-decklink-helper.

Requires Blackmagic Desktop Video, from blackmagicdesign.com/support. The plugin sends a clean feed: no OSD, no subtitles, and no colour conversion — code values are rescaled and repacked only, so HDR material reaches the card carrying its original values.
